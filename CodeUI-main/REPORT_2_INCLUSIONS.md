## 1. Product Mission & Core Principles

CodeUI is an open-source, lightweight, **lab-safe desktop Integrated Development Environment (IDE)** built on **Tauri 2**, **Rust**, **React 18**, and **Monaco Editor**. It is specifically engineered for college computer laboratories, practical programming exams, and restricted academic evaluation environments.

### The Four Core Tenets:
1. **Zero AI & Examination Integrity:**
   Strictly suppresses autocomplete, IntelliSense, Copilot, snippets, and automated suggestions. Students must write syntax from memory, matching exam testing standards.
2. **Supervised Process Sandboxing:**
   Student code runs in isolated process groups managed by a Rust watchdog with configurable timeout limits (default 12 seconds). Runaway loops, deadlocks, and fork bombs are terminated automatically without leaving orphaned processes on shared lab computers.
3. **Clean Scratch Builds:**
   All compilation artifacts (object files, binaries, `.class` files) are emitted into isolated temporary scratch directories outside the student's project folder, keeping project directories clean.
4. **Self-Contained All-in-One Workspace:**
   Eliminates constant window-switching between text editors and external terminal windows by providing an integrated terminal, one-click execution bar, file explorer, search, and syntax highlighting.

## 3. Frontend Architecture (`CodeUI-main/src/`)

The frontend is built using **React 18** and **TypeScript**, styled with bespoke **Vanilla CSS** (`src/index.css`), and bundled using **Vite 6**.

### 3.1 Application Shell (`src/App.tsx`)
- Coordinates the main desktop layout: custom title bar, activity bar, collapsible sidebar, dual-pane editor area, and bottom terminal/preview panel.
- Binds global keyboard shortcuts:
  - `Ctrl + S`: Save active document dynamically.
  - `F5`: One-click compile and run active file.
  - `Ctrl + P`: Quick Open file palette.
  - `Ctrl + ,`: Settings modal.
  - `Ctrl + \`: Split editor pane side-by-side.
  - `Ctrl + ` ` (Backtick)`: Toggle bottom panel.
  - `Ctrl + B`: Toggle sidebar visibility.
  - `Ctrl + Shift + E` / `Ctrl + Shift + X`: Switch between Explorer and Extensions.
- Manages drag-and-drop panel and sidebar resizing with mouse tracking.

### 3.2 Global State Store (`src/store/useWorkspaceStore.ts`)
A centralized custom hook managing all core application state:
- **Workspace State:** Active workspace root directory path, directory cache (`dirCache`), expanded folder set, loading folders.
- **File Management:** List of `openFiles`, active file path, split editor file path, dirty state tracking, and content buffers.
- **Terminal & Process Bridge:** Canonical PTY session ID, shell detection, and process runner event subscription.
- **User Settings:** Theme, font size, tab width, execution timeout, and recent folders.

### 3.3 Shell Components (`src/components/shell/`)
1. **`TitleBar.tsx`:** Custom frameless title bar with native Tauri window controls (minimize, maximize, close), search trigger button, sidebar/panel toggle buttons, and functional drop-down menus (`File`, `Edit`, `Selection`, `View`, `Go`, `Run`, `Terminal`, `Help`).
2. **`ActivityBar.tsx`:** Left-hand icon strip enabling one-click navigation between `Explorer`, `Search`, `Run & Debug`, and `Extensions`, plus a bottom `Settings` gear.
3. **`Sidebar.tsx`:** Dynamic container rendering whichever sidebar tool is active, with integrated file and folder action buttons.
4. **`StatusBar.tsx`:** Bottom status bar displaying:
   - Green `Lab Safe Mode` security shield.
   - Diagnostic error and warning counts.
   - Live cursor line and column (`Ln X, Col Y`).
   - Tab width toggle (2 vs 4 spaces).
   - Character encoding (`UTF-8`) and line ending (`LF` / `CRLF`).
   - Active language picker with 25+ selectable languages.
5. **`Toasts.tsx`:** Non-intrusive animated notification toasts with auto-dismiss timers.

### 3.4 Editor Subsystem (`src/components/editor/`)
1. **`MonacoEditorGroup.tsx`:**
   - Wraps `@monaco-editor/react`.
   - Mounts models using clean normalized file URIs (`file:///...`).
   - Enforces the custom high-contrast dark theme (`codeui-dark`).
   - Subscribes to Monaco cursor change events and marker updates.
   - Binds `Ctrl + S` dynamically to the currently focused model to prevent stale closure bugs.
   - Includes top breadcrumb bar showing file icon, filename, and extension stem.
2. **`SplitEditorContainer.tsx`:** Provides side-by-side dual-editor panes, allowing students to inspect headers or reference code while writing their solutions.
3. **`TabStrip.tsx`:** Tab management strip supporting close buttons, dirty dot indicators, and tab switching.
4. **`RunDebugBar.tsx`:** Action bar above the editor with a prominent green **Run** button, file path indicator, and terminal quick-launch.
5. **`monacoSafeDefaults.ts`:** Lab-safe Monaco editor settings:
   - `quickSuggestions: false`
   - `suggestOnTriggerCharacters: false`
   - `snippetSuggestions: "none"`
   - `wordBasedSuggestions: "off"`
   - `tabCompletion: "off"`
   - `parameterHints: { enabled: false }`
   - `hover: { enabled: "off" }`

### 3.5 Explorer Subsystem (`src/components/explorer/`)
1. **`FileTree.tsx`:**
   - Recursive directory tree renderer.
   - On-demand folder loading with spinner animations.
   - Context menu actions: New File, New Folder, Rename, Delete, Open to Side, Copy Path, Reveal in File Manager.
   - Built-in symbol outline extractor (`parseOutline`) that regex-scans Java, C, C++, and Python files for class and function declarations.
2. **`RunPanel.tsx`:** Sidebar execution panel displaying target file metadata, active compiler status, and one-click run trigger.
3. **`SearchPanel.tsx`:** Workspace-wide text search tool with debounced queries, case-sensitivity toggles, and grouped file results.

### 3.6 Extensions & Preview (`src/components/extensions/` & `preview/`)
1. **`ExtensionsPanel.tsx`:** Browse installed toolchains, recommended packages, and query the live Open VSX Marketplace via REST API.
2. **`ExtensionDetailView.tsx`:** Displays extension READMEs and licensing using Marked.js.
3. **`ExtensionIcon.tsx`:** Brand icons for languages and tools (Salivo, Clangd, Python, Docker, Go, Rust, Java).
4. **`PreviewPanel.tsx`:** Sandboxed iframe renderer for instant HTML/CSS/JavaScript web preview with auto-refresh on save.

### 3.7 Modals & Palettes (`src/components/`)
1. **`QuickOpenModal.tsx`:** Fuzzy file navigation dialog (`Ctrl + P`) with live keyboard arrow navigation.
2. **`SettingsModal.tsx`:** Configuration dialog for theme selection, font sizing (12–24px), tab width, shell executable selection, and watchdog execution timeout (5–300s).
3. **`WelcomeView.tsx`:** Dashboard displaying quick actions, recent workspace folders, and starter walkthrough guides.

## 4. Frontend Services Layer (`CodeUI-main/src/services/`)

All OS and backend communications are encapsulated in modular TypeScript services:

| Service | File | Purpose |
| :--- | :--- | :--- |
| **Filesystem** | `fsService.ts` | IPC bridge for file read/write, directory listings, path exist checks, folder dialogs, file search. |
| **Terminal** | `ptyService.ts` | IPC bridge to spawn, write, resize, and kill PTY sessions. Includes mock fallback for browser testing. |
| **Process** | `processService.ts`| IPC bridge to invoke `run_file`, terminate runs, write stdin, and subscribe to batched output/status events. |
| **Editor** | `editorService.ts` | Global editor registry, model marker setter/clearer for compiler errors, cursor position tracking. |
| **Diagnostics**| `diagnostics.ts` | Extracts system info, formats markdown report, and parses GCC/Clang/Javac compiler errors into Monaco squiggles. |
| **Settings** | `settingsService.ts`| Loads and persists user settings to backend JSON or browser localStorage. |
| **Extensions**| `extensionService.ts`| Open VSX marketplace search client, AI extension policy filter, and metadata cache. |
| **Notifications**| `notify.ts` | Global pub/sub event bus for error, warning, and info toast messages. |

## 5. Backend Architecture (`CodeUI-main/src-tauri/`)

The backend is built in **Rust** using the **Tauri 2** framework, exposing native OS capabilities through type-safe IPC commands.

### 5.1 Main Entry & App Lifecycle (`lib.rs` & `main.rs`)
- Initializes managed state: `RunRegistry`, `PtyManager`, and `SettingsStore`.
- Registers 28 Tauri IPC commands across filesystem, process, terminal, environment detection, settings, and diagnostics.
- Implements `on_window_event` close hook (`shutdown()`) ensuring all running student processes, compilers, and PTY shells are terminated when the application window closes.

### 5.2 Native Command Surface (`src-tauri/src/commands/`)
1. **`fs.rs` (Filesystem Engine):**
   - `read_file`: UTF-8 validated file reading.
   - `write_file`: Atomic save using sibling temporary files and permissions preservation.
   - `list_dir`: Reads directory entries, mapping sizes and modified timestamps.
   - `create_file` / `create_dir`: Recursive folder and file creation.
   - `rename_file` / `delete_file`: Atomic rename and recursive folder deletion.
   - `pick_folder` / `pick_file`: Native OS file-picker dialogs via `rfd`.
   - `open_in_file_manager`: Reveals files in Windows Explorer, macOS Finder, or Linux file managers.
   - `search_files`: Multi-threaded ripgrep-style workspace text search.
   - `find_files`: Recursive filename search with max-result limits.
2. **`process.rs` (Process Runner Engine):**
   - `run_file`: Builds and executes source code in isolated scratch directories with a background watchdog timeout.
   - Batches output in 8 KB / 30ms chunks (`FLUSH_BYTES`, `FLUSH_INTERVAL`) to prevent UI freezes on high-frequency print loops.
   - Limits output forwarding to 5 MB (`OUTPUT_CAP`) to protect the WebView from memory exhaustion.
   - `stop_run`: Forcefully kills active execution tree.
   - `write_run_stdin` / `close_run_stdin`: Routes standard input to the running binary.
3. **`terminal.rs` (PTY IPC Surface):**
   - `spawn_pty`: Spawns native pseudo-terminals with specified rows, cols, working dir, and shell.
   - `write_pty`: Writes keystrokes and data to the PTY stdin.
   - `resize_pty`: Updates terminal window dimensions.
   - `kill_pty`: Terminates PTY sessions.
   - `get_default_shell`: Detects OS default shell (PowerShell/CMD on Windows, `$SHELL` on Unix).
4. **`env_detect.rs` (Toolchain Detection):**
   - Automatically probes `$PATH` and augmented system paths for:
     - `gcc` (C compiler)
     - `g++` (C++ compiler)
     - `javac` & `java` (Java JDK)
     - `python` / `py` / `python3` (Python interpreter)
     - `sf` (Salivo language driver)
5. **`settings.rs` (Settings Persistence):**
   - Manages user settings persisted to `~/.config/codeui/settings.json` (or Windows `%APPDATA%\codeui\settings.json`).
   - Implements a 400ms debounce buffer to collapse rapid UI changes (slider adjustments) into single disk writes.
6. **`diagnostics.rs` (System Diagnostics Snapshot):**
   - Returns compile-time metadata (`CODEUI_GIT_SHA`, `CODEUI_BUILD_TIME`, profile, target triple, OS, architecture, active PTYs, detected tools).

### 5.3 Process Isolation & Toolpath Resolution (`src-tauri/src/proc/`)
1. **`kill.rs` (Escalating Process Termination):**
   - Prevents orphaned processes on shared lab machines.
   - Unix: Uses `libc::killpg` to signal negative PID process groups, escalating from `SIGTERM` (with grace period) to `SIGKILL`.
   - Windows: Uses `taskkill /PID <pid> /T /F` to terminate the entire process tree.
2. **`toolpath.rs` (Augmented Toolpath Resolution):**
   - Augments the system `PATH` with standard compiler locations:
     - Windows: `C:\msys64\ucrt64\bin`, `C:\MinGW\bin`, `C:\Program Files\LLVM\bin`, `C:\Program Files\Git\bin`, `%USERPROFILE%\.cargo\bin`, `%USERPROFILE%\.salivo\bin`, `%LOCALAPPDATA%\Programs\Python`.
     - Linux/macOS: `/usr/local/bin`, `/usr/bin`, `/snap/bin`, `~/.local/bin`, `~/.cargo/bin`, `~/.salivo/bin`, `$JAVA_HOME/bin`.
   - Bypasses 0-byte WindowsApps execution alias stubs (which would otherwise trigger Microsoft Store popups).
3. **`pty/mod.rs` (Pseudoterminal Engine):**
   - Wraps `portable-pty` crate.
   - Manages asynchronous reader threads that forward terminal output chunks to Tauri event listeners (`pty-data-<id>`).

### 5.4 Language Runners (`src-tauri/src/runners/`)
All language compilation and execution logic is implemented via the `LanguageRunner` trait:

1. **C Runner (`c.rs`):** Compiles via `gcc -Wall -g -o <scratch>/<stem> <source>`, runs from project directory.
2. **C++ Runner (`cpp.rs`):** Compiles via `g++ -Wall -g -std=c++17 -o <scratch>/<stem> <source>`, runs from project directory.
3. **Java Runner (`java.rs`):**
   - Strips comments and string literals to accurately parse `package` declarations.
   - Detects the `public class` declaration and verifies that the class name matches the `.java` filename before compiling.
   - Compiles via `javac -d <scratch> <source>`.
   - Executes via `java -cp <scratch> <package.Class>`.
4. **Python Runner (`python.rs`):**
   - Detects `python`, `py`, or `python3`.
   - Runs with `-u` for unbuffered stdout/stderr streaming.
5. **Salivo Runner (`salivo.rs`):**
   - Official language driver for the Salivo systems programming language.
   - Compiles via `sf build <source>` in scratch directory.
   - Executes the compiled native binary from project directory.

## 6. Language Grammars & Monarch Tokenizers (`src/languages/`)

CodeUI includes built-in offline syntax highlighters so no internet connection is required:

1. **`salivoMonaco.ts`:**
   - Full Monarch grammar for the Salivo programming language.
   - Highlights stream header imports (`><`), types (`int`, `float`, `string`, `StrSlice`, `ByteSlice`, `Option`, `Result`, `Vec`, `Map`, `Heap`, `BTree`), monads, template strings (`$""`), and RAII `pub trait Drop`.
2. **`registerAllLanguages.ts`:**
   - Eagerly registers Monarch grammars for **C, C++, Java, Python, Rust, Go, C#, Shell, PowerShell, Markdown, HTML, CSS, YAML, SQL, PHP, Ruby, and Zig**.

## 7. Build Automation & Tooling

1. **`xtask/`:**
   A dedicated Rust workspace CLI for automated developer tasks:
   - `cargo run -p xtask -- version-sync`: Synchronizes version numbers across `Cargo.toml`, `package.json`, and `tauri.conf.json`.
   - `cargo run -p xtask -- bump <version>`: Atomically bumps workspace version everywhere.
   - `cargo run -p xtask -- audit-no-python`: Enforces repository purity by failing if any `.py` script is tracked.
2. **Bundled Monospace Font:**
   Includes `src/assets/fonts/CodeUI-Mono.ttf` bundled into production distributions to guarantee consistent character cell measurements across Windows, macOS, and Linux without font-drift bugs.
3. **Packaging Configurations:**
   - `tauri.conf.json`: Configured for NSIS installer, Windows MSI, Debian `.deb`, AppImage, and macOS `.dmg`.
