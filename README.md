# CodeUI
# CodeUI  **CodeUI** is a lightweight, Linux-first desktop Integrated Development Environment (IDE) designed specifically for college computer laboratories.  The project was born from a simple problem: many college labs rely on basic text editors such as Notepad because full-featured IDEs like VS Code provide features such as autocomplete and code suggestions that may be inappropriate during practical examinations.  CodeUI aims to provide students with a proper programming environment without turning the editor into an automated coding assistant.  The initial version will focus on:  - A clean, modern editor interface - Integrated terminal - File and project management - C and C++ development - Python development - Java development - HTML, CSS and JavaScript development - Compilation and execution of supported languages - Administrative configuration - A controlled Practical Mode - Environment detection for required compilers and runtimes  CodeUI will **not** provide autocomplete, code suggestions, AI coding assistance, automatic grading, student rankings, or other features intended to assist students in producing solutions during practical work.  ### Target Environment  CodeUI will be developed and tested primarily for **Ubuntu/Linux**, reflecting the environment used in the target college laboratories. Cross-platform support, particularly Windows, may be explored after the Linux version reaches a stable state.  ### Project Goal  The goal of CodeUI is not to compete with general-purpose IDEs such as VS Code.  Instead, it aims to provide a **simple, controlled and college-focused programming environment** that sits between the limitations of basic text editors and the extensive assistance provided by modern development environments.  ### Development Philosophy  CodeUI is being developed incrementally as a collaborative project involving human developers and AI-assisted development.  The focus is on:  **Build → Understand → Test → Break → Fix → Improve**  The first objective is a functional and reliable **v0.1**, with future features determined by real-world testing and feedback from college laboratory use.
