# CodeUI Installers

Official standalone release packages for CodeUI across all major platforms.

| Operating System | Package Type | File | Description |
| :--- | :--- | :--- | :--- |
| **Windows** | NSIS Setup Executable | [`CodeUI_0.1.0_x64-setup.exe`](./CodeUI_0.1.0_x64-setup.exe) | Double-click to run the setup wizard (per-user or all-users). |
| **macOS** | Apple Disk Image | [`CodeUI_0.1.0_aarch64.dmg`](./CodeUI_0.1.0_aarch64.dmg) | Drag `CodeUI.app` into `/Applications`. |
| **Linux (Debian/Ubuntu)** | Native `.deb` Package | [`CodeUI_0.1.0_amd64.deb`](./CodeUI_0.1.0_amd64.deb) | Install with `sudo dpkg -i CodeUI_0.1.0_amd64.deb`. |
| **Linux (Universal)** | Standalone `.AppImage` | [Download AppImage (83.7 MB)](https://github.com/iamriteshhh/CodeUI/releases/download/v0.1.0-1/CodeUI_0.1.0_amd64.AppImage) | Portable binary. Run `chmod +x CodeUI_0.1.0_amd64.AppImage && ./CodeUI_0.1.0_amd64.AppImage`. |
